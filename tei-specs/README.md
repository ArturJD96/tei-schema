# tei-spec

The `build.ts`, for each TEI spec (at `./TEI/P5/Source/Specs/`), creates a directory containing a schema and testing file.

Those test cases are in the style of JSON Schema Test Suite (complied to [their schema](https://raw.githubusercontent.com/json-schema-org/JSON-Schema-Test-Suite/refs/heads/main/test-schema.json).)
